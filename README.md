# BiblioCampus

Sistema web para gestionar el catálogo, reservas online, préstamos a domicilio, lista de espera y sanciones de una biblioteca educativa.

## Estructura del repositorio

- `docs/`: documentación funcional y técnica (`idea.md`, `decisiones.md`, `glosario.md`, `preguntas-abiertas.md`, `spec.md`). La fuente de verdad funcional es `docs/spec.md`.
- `backend/`: código y tests del servidor y base de datos.
- `frontend/`: aplicación web cliente.
- `.cursor/rules/`: definición de roles especializados para agentes.
